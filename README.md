## 📌 Overview
A Machine Learning based web application that detects phishing emails using NLP and Scikit-learn.
## Project Overview

The Phishing Email Detection System is a machine learning-based web application designed to identify and classify phishing emails. The project helps users analyze suspicious email content and determine whether the email is legitimate or potentially malicious.

The main objective of this project is to improve cybersecurity awareness by helping users recognize phishing attacks, which are one of the most common forms of cybercrime. The system is designed with a simple and user-friendly interface so that anyone can easily test suspicious emails.
This project demonstrates practical implementation of:
- Machine Learning
- Natural Language Processing (NLP)
- Cybersecurity concepts
- Flask web development
- Model deployment integration

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/dhanyasreegopinigari-blue/phishing-email-detection-system.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Train Model

```bash
python train_model.py
```

### Run Application

```bash
python app.py
```
